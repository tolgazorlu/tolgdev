<h1>tolgdev</h1>

Personal portfolio website showcasing projects, skills, and experience.

[Live site](https://tolg.dev) (projeyi buradan inceleyebilirsiniz)

![](https://github.com/tolgazorlu/tolgdev/blob/main/video.gif?raw=true)

You can use Google Chrome for better experiences.

## Features
- Home, About, Blog and Contact pages (React Router)
- Animated hero, experience timeline and works sections (Framer Motion)
- Contact form via EmailJS
- Responsive layout with Tailwind CSS / DaisyUI, dark mode toggle

## Tech stack
React 18, Vite, Tailwind CSS, DaisyUI, Framer Motion, EmailJS, React Router.

## Project structure
```
src/
  pages/        HomePage, AboutPage, BlogPage, ContactPage
  components/   Navbar, Footer, Home (Hero, Card, Contact, Experiences, Works)
public/
```

## 💻 Proje Kurulum

- Adım 1 - Bu projeyi bilgisayarınıza klonlayın:
  `git clone https://github.com/tolgazorlu/tolgdev`

- Adım 2 - Projede dizinine gidin, gerekli modülleri yükleyin ve projeyi çalıştırın:
  `cd tolgdev`
  `npm install`
  `npm run dev`
